## 0. Суть продукта (зафиксировано)

Ты делаешь **агрегатор нейросетей для разработки**, но не «ещё один Polza».

**Отличие:** берёшь дешёвые (в т.ч. китайские) модели, **соединяешь их в одну команду** и получаешь результат уровня **Claude Fable 5** за копейки.

Два входа для клиента:

| Кто | Как пользуется |
|-----|----------------|
| Обычный человек | Сайт: оплатил → playground / проект → выбрал модели → пишет код в вебе |
| Прошаренный | Берёт **универсальный API-ключ** → Cursor / VS Code / Continue / Roo / Cowork / что угодно с OpenAI-compatible endpoint |

Обучение «как подключить ключ» — **фаза 2**, не блокер запуска.

Мечта дальше MVP: **сообщество кодеров** (розыгрыши, сходки, мероприятия). В MVP закладываем только продукт, комьюнити — после первых юзеров.

## 1. Позиционирование

### Месседж

> Команда дешёвых моделей работает как топовая Fable.  
> Один ключ — во все IDE. Один сайт — разработка без установки редактора.

### Доказательство (лендинг)

Пост / бенчмарк OpenRouter Fusion:

- связка **Gemini 3 Flash + Kimi K2.6 + DeepSeek V4 Pro** ≈ **64–65%**
- solo **Claude Fable 5** ≈ **65%**
- одиночные дешёвые модели заметно слабее

На старте можно поставить чужой график с дисклеймером; **свой прогон** — сделать как можно раньше и заменить.

### Чем НЕ являемся

- Не универсальная «болталка на 400 моделей»
- Не enterprise-шлюз с НДС ×4 (ProxyAPI)
- Не просто реселл ключей без своей фичи

## 2. Две киллер-фичи (обязательны)

### 2.1 Fusion — команда моделей ≈ Fable

Как в посте про OpenRouter Fusion:

- в стопку ставятся дешёвые модели (не обязательно топовые);
- дефолт: **Gemini 3 Flash + Kimi K2.6 + DeepSeek V4 Pro**;
- сценарий из поста: ревью проекта → правки → долго шуршат → траты ~$1.

В продукте это режим / пресет команды, а не «ещё одна модель в списке».

### 2.2 Ultra Mode — 4 субагента параллельно

**Главное нововведение продукта:**

Четыре субагента одновременно работают над разными частями одной задачи, потом объединяют результат:

1. Frontend  
2. Backend  
3. Tests  
4. Documentation  

Затем **синтез** (обычно DeepSeek) → один цельный результат.

В UI: видно, что агенты работают параллельно (статусы), не чёрный ящик на 2 минуты молчания.

## 3. Что входит в MVP-сайт (жёсткий скоуп)

### Экраны (4 + сущности)

1. **Лендинг** — месседж, график Fusion vs Fable, CTA, блок «ключ во все IDE»  
2. **Dashboard** — баланс, API-ключи, расход токенов  
3. **Playground + Проекты** — обязательны  
4. **Billing** — пополнение

### Обязательные сущности продукта

| Сущность | Статус | Зачем |
|----------|--------|--------|
| **Проекты** | must | рабочая единица разработки, не одноразовый чат |
| **История генераций** | must | вернуться, сравнить, не потерять работу |
| **Мультичат** | must (в рамках проекта) | несколько веток диалога |
| **Playground** | must | разработка без установки VS Code |
| **API-ключ** | must | Cursor, VS Code, Continue, Roo, Cowork… |
| **Prompt Caching** | must | до −90% на повторном контексте проекта |
| **GitHub export / commit** | must в MVP-продукте* | commit, push, откат коммитов |
| **Саппорт Telegram** | must | единственный канал поддержки v1 |
| **Оферта + Privacy** | must | пишем сразу |
| **Логи** | храним | для отладки, биллинга, саппорта |

\* «Серверы под аренду / полноценный cloud-IDE без локального редактора» — **видение есть, инфраструктуры пока нет**. В MVP: мощный веб-playground + проекты + git. Аренда серверов / remote env — **фаза после MVP**.

### Интеграции API

- Формат: **OpenAI-compatible** (`/v1/chat/completions` и нужное для IDE).
- Цель: **везде, где вставляется base URL + API key** — VS Code, Cursor, Continue, Roo, Cowork и т.д.
- Каталог моделей: западные chat-модели с основного upstream + китайские (DeepSeek / Kimi) со второго, если на первом нет.

Себестоимость юзеру **не показываем** — только его цены на токены / баланс.

## 6. Технический каркас (для разработки)

```
Пользователь
 ├─ Web (лендинг / кабинет / playground / проекты)
 └─ IDE (OpenAI-compatible API key)
        │
        ▼
 Твой Backend
 ├─ Auth (ИП-продукт, аккаунты)
 ├─ Billing (×1.5, карта РФ, CryptoBot)
 ├─ Projects / Chats / History
 ├─ Prompt Cache passthrough
 ├─ Ultra Mode оркестратор (4 агента + синтез)
 ├─ Fusion-пресет (Gemini + Kimi + DeepSeek)
 ├─ GitHub OAuth → commit / push / rollback
 ├─ Логи запросов
 └─ Telegram support deep-link
        │
        ▼
 Upstream
 └─ основной провайдер (+ опционально DeepInfra/IKunCode)
```

### Модели в API

| model id (пример) | Поведение |
|-------------------|-----------|
| `ultra-mode` | 4 агента + синтез |
| `fusion-fable` | команда Gemini + Kimi + DeepSeek |
| `gemini-3-flash` и др. | обычный одиночный прокси |

Имена model id уточним по реальному каталогу upstream на этапе 0.

### Стек (простой)

- Frontend: Next.js  
- Backend: FastAPI или Node  
- DB: Postgres (проекты, история, биллинг)  
- Файлы проекта: object storage или git-репо на пользователя  
- Деплой: один VPS
