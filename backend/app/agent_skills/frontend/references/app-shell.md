# App shell — контракт (не клон шаблона)

Интент **app** = мини-продукт под **бриф юзера**.  
Разные задачи → разный бренд, ниша, тексты, визуал, поля карточек, UX.  
**Запрещено** всем сдавать один и тот же UI с подменой названия.

`templates/app-shop*` — **пример плотности и рабочих потоков**, не обязательный внешний вид.
Имена классов (`panel__head`, `brand__meta`, …) **не** DoD.

## DoD (что должно работать)

1. **Shell:** бренд из брифа + навигация ≥2 экранов (каталог / заказ|корзина / история — или эквивалент под задачу).
2. **Каталог:** список из API, фото, цена, CTA; фильтры/чипы **совпадают** с `category`/`tag` в seed.
3. **Заказ:** форма с `fetch` + `res.ok` + error/empty/loading; для grocery/cart — корзина + badge.
4. **История:** экран заказов, данные с API (не заглушка «недоступна»).
5. **Файлы:** `index.html` + `styles.css` + `app.js`; логика **только** в `app.js` (нет inline `<script>`).
6. **API:** `const API = "."` (или относительные `./api/…`).
7. **Плотность:** не 2KB-скелет — полноценный CSS/JS под этот продукт (ориентир HTML≥3KB, CSS≥4KB, JS≥3.5KB).

## Изобретай под бриф

| Из брифа | Твоё решение |
|----------|----------------|
| Название, город, тон | chrome, копирайт, телефон |
| Ниша (цветы / еда / книги / …) | поля карточки, фильтры, CTA |
| Цвета/настроение | `:root`, типографика, layout |
| Потоки | какие экраны и как названы |

## Бан

- сдать эталон byte-for-byte «Букет Лайн / Свежая Полка» без адаптации под бриф
- лендинг (hero/услуги) вместо app-shell
- React без просьбы; `alert` success; `onclick=`
- логика в HTML; `API=""`; мёртвые картинки; filters ≠ seed
- продукты с `composition/size/stems`; grocery без корзины

## Gate (поведение)

| Код | Смысл |
|-----|--------|
| `thin_app_*` / `thin_styles` | скелет, нет реальной логики экранов |
| `missing_filters` / `filter_seed_mismatch` | фильтры ↔ seed |
| `missing_cart` | grocery без корзины |
| `inline_script_in_html` | логика в HTML |
| `thin_catalog` / `dead_pick_cta` | карточки/CTA мертвы |
| `wrong_product_shape` | сдан лендинг |

## DoD checklist

- [ ] Уникально под бриф (не клон чужого магазина)
- [ ] ≥2 экрана + nav работают
- [ ] каталог + заказ/корзина + история end-to-end
- [ ] filters ↔ seed; live images; `API="."`
- [ ] вся логика в `app.js`
