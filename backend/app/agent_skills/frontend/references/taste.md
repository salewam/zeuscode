# Taste — анти-пресность (не один шаблон)

Контент есть ≠ вкусно. Если страница «как шаблон / как прошлый клиент» — FAIL.
**Уникальность:** каждый юзер = свой бренд / H1 / адрес / палитра / каркас из брифа.
Чужой бренд или чужой визуальный штамп при другом брифе = FAIL (clone).

Эталон `good_landing_sto` — **планка плотности и честности**, не обязательный UI для всех ниш.

## Универсальные must

### 1) Ссылки и CTA не «браузерные»
Явно задай цвет ссылок/кнопок из токенов. Бан: дефолтный `rgb(0,0,238)` в шапке.

### 2) Реальный визуальный якорь
Hero/витрина = предметная сцена под нишу (не пустой градиент). Размер медиа достаточный, чтобы «ударить», не postage-stamp.

### 3) H1 без корпоративной воды
**Бан в H1:** «Профессиональный…», «Качественный…», «Комплексный сервис».  
**Делай:** конкретика места/оффера из брифа.

### 4) Ритм и иерархия
Отзывы/шаги/карточки — не голый HTML: отступы, разделители, hover. Свой паттерн под нишу.

### 5) Proof + footer
Есть доверие (отзыв/факт/гарантия) и footer с реальными контактами из брифа (`tel:` если телефон).

### 6) Карточки живые
Hover/transition или иной явный интерактив. Текст услуги = факты + цена, не egg-copy.

### 7) Форма не одинокая
Секция заявки: заголовок + короткий sub + поля с нормальным padding.

## Если ниша = автосервис / СТО
Можно опираться на асфальт/янтарь, крупную витрину, жирные карточки услуг — **только** если бриф про авто.  
Иначе изобрети палитру и каркас под продукт.
