# Content fill — плотность + UNIQUE (не штамп)

Дешёвая модель берёт **UNIQUE брифа** (бренд, H1, услуги, палитра, IA).
`good_*` = планка **качества**, не бренд и не обязательный набор id/классов.

## Уникальность (major если слил)

- Бренд / H1 / адрес / телефон / прайс / отзывы — из **этого** брифа
- Порядок секций — под продукт, не «как в прошлом клиенте»
- **Бан:** сдать всем один МоторХаус/Каширское/120-45-67 или один и тот же каркас с заменой названия

`data-uniq` на `<html>` — полезен, но не фетиш: важнее видимая уникальность контента.

## Лендинг — must ship (смысл, не шаблон)

| # | Обязательно по смыслу |
|---|------------------------|
| 1 | Header с брендом + способ связаться |
| 2 | Hero: media-якорь + оффер из брифа + CTA |
| 3 | Визуальный ряд / витрина / галерея — **≥3 живых кадра** (img или осмысленный media), сюжет под нишу |
| 4 | Услуги/оффер: достаточно карточек с фактами и ценой «от», если это услуга |
| 5 | Доверие: шаги и/или отзывы и/или FAQ — что подходит продукту |
| 6 | Форма / запись без лжи в `catch` |
| 7 | Footer: реальные контакты из брифа |
| 8 | `styles.css` с `:root` из палитры UNIQUE |

Плотность: страница не «пустая оболочка». Конкретные `#vitrine` / `.top__nav` / «ровно 6 article» — **не закон**, если смысл закрыт иначе.

## Визуал

- Media читается, не postage-stamp
- Live URL из Media pack когда есть
- Motion + mobile + anti-AI look

## Бан (major)

- Клон чужого бренда/штампа
- Пустой hero / browser-blue / egg H1
- Фейк-форма / placeholder телефон
- indigo / Inter

## Self-check

- [ ] UNIQUE брифа глазом
- [ ] не чужой штамп
- [ ] media + оффер + контакты + честная форма
