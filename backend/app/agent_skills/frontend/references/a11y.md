# Frontend — Accessibility

Цель: **WCAG 2.2 Level AA** на практике. Не эссе — чеклист + паттерны.

---

## Must (каждый UI)

1. Клавиатура: Tab по действиям; Enter/Space на кнопках; Esc закрывает dialog.
2. Focus видим: `:focus-visible` с кольцом; не убивай outline без замены.
3. Имена: icon-only → `aria-label` (или видимый текст).
4. Формы: `<label for="id">` + `id`; ошибка → `aria-invalid` + `aria-describedby`.
5. Контраст: текст ~4.5:1; крупный (~18pt+/14pt bold) ~3:1.
6. Не только цвет: ошибка/успех = текст (± иконка).
7. Motion: `@media (prefers-reduced-motion: reduce)`.
8. Hit target ≥ 24×24 CSS px (лучше ≥ 44×44 на тач).
9. Один `h1`; заголовки по порядку.
10. Live-ошибки: `role="alert"` или `aria-live="assertive"` для критичных.

## Patterns

### Button vs link

```html
<button type="button">Сохранить</button>
<a href="/projects/new">Новый проект</a>
<!-- плохо: <div onclick="..."> -->
```

### Form error

```html
<label for="email">Email</label>
<input id="email" type="email" aria-invalid="true" aria-describedby="email-err" />
<p id="email-err" class="field-error" role="alert">Введите корректный email</p>
```

### Dialog

```html
<dialog id="confirm" aria-labelledby="confirm-title">
  <h2 id="confirm-title">Удалить ключ?</h2>
  <p>Действие нельзя отменить.</p>
  <button type="button" data-close>Отмена</button>
  <button type="button" data-confirm>Удалить</button>
</dialog>
```

```js
const dlg = document.getElementById("confirm");
const opener = document.getElementById("open-confirm");
opener.addEventListener("click", () => {
  dlg.showModal();
  dlg.querySelector("[data-close]").focus();
});
dlg.addEventListener("close", () => opener.focus());
```

### Empty

```html
<section class="empty" aria-labelledby="empty-title">
  <h2 id="empty-title">Пока нет проектов</h2>
  <p>Создайте первый — чаты появятся здесь.</p>
  <button type="button" id="create-project">Создать проект</button>
</section>
```

### Loading

```html
<div aria-busy="true" aria-label="Загрузка списка">
  <!-- skeleton blocks -->
</div>
```

---

## Anti-a11y (запрет)

- Clickable card без `<button>`/`<a>` внутри
- Placeholder-as-label
- Автоплей со звуком
- Focus outline убит навсегда
- Модалка без возврата фокуса
- Контент только картинкой без alt/текста
