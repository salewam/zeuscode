# Скелет продуктов ZeusCode

Одна форма на любой продукт. Не расписывай скилл «навсегда» заранее —
заполни **каркас**, остальное добей на тестах (verify + reviewer).

## Как пользоваться

1. Скопируй строку в [`REGISTRY.md`](./REGISTRY.md) для нового типа (CRM, PDF, …).
2. Заполни [`PRODUCT_FORM.md`](./PRODUCT_FORM.md) — один файл = один тип продукта.
3. Если нужен новый агент-пак — скопируй папку [`SKILL_PACK_TEMPLATE/`](./SKILL_PACK_TEMPLATE/) → `../имя/`.
4. Intake всегда один: [`INTAKE_BRIEF.md`](./INTAKE_BRIEF.md).
5. На тестах правь только: `checklist`, `anti-patterns`, `verify.sh`, 1–2 `examples`.

## Правило

| Сейчас | Потом на тестах |
|--------|-----------------|
| id, зона путей, команда ролей, что сдаём, минимальный verify | анти-паттерны, edge cases, рубрики, шаблоны |

Не пиши 50 страниц SKILL.md до первого живого прогона.
