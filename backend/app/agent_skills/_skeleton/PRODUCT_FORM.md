# Product Form — заполни и готово к тестам

Скопируй этот файл → `_skeleton/products/<id>.md`  
Пример: `products/crm.md`, `products/pdf.md`, `products/landing.md`

Заполняй поля в `` `backticks` `` / после `→`. Пустое = добьём на тестах.

| design | → | |

**Порядок волн (как pipeline):**

## 5. Intake (какие вопросы оркестратор задаёт)

Отметь нужное или допиши. Голос = те же ответы через STT.

- [ ] Для кого это? (аудитория)
- [ ] Какой результат нужен? (файл / сайт / кабинет)
- [ ] 3 must-have
- [ ] Бренд / название / контакты
- [ ] Есть ли данные/интеграции? (Telegram, оплата, CRM, таблицы)
- [ ] Стиль (строго / ярко / минимал) — 1 слово
- [ ] Другое → ` `

Полный шаблон brief: [`INTAKE_BRIEF.md`](./INTAKE_BRIEF.md)
