# Intake Brief — универсальный

Оркестратор всегда собирает этот brief **до** вызова скиллов.  
Голос: те же поля, ответы из STT.

```yaml
product_id: ""          # из REGISTRY: landing | app | crm | deck | pdf | …
title: ""
audience: ""            # для кого
outcome: ""             # что получит человек (открыть/скачать)
must_have:
  - ""
  - ""
  - ""
brand:
  name: ""
  contacts: ""          # телефон/telegram/email — реальные, не example.com
  tone: ""              # 1 слово: строго | тепло | ярко | минимал
data:
  entities: []          # клиент, заказ, сделка…
  integrations: []      # telegram | оплата | таблицы | …
constraints:
  mobile_first: true
  language: "ru"
  cheap_models: true
out_of_scope: []        # чего НЕ делаем в этом ходе
```

## Вопросы человеку (порядок)

1. Что хотите получить на выходе? (сайт / приложение / CRM / презентация / PDF / другое)
2. Для кого?
3. Название и как связаться с вами/клиентом?
4. Три вещи, без которых результат бесполезен?
5. Нужны данные или интеграции? Какие?
6. Стиль одним словом?
7. Что точно не надо делать сейчас?

Если человек надиктовал кашу — оркестратор **сам** раскладывает в YAML выше и показывает на подтверждение одной карточкой.
