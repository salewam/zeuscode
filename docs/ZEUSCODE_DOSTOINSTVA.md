# ZeusCode — достоинства проекта

Маркетинческий файл. Источник правды для приветствия бота и советника.
Пиши человеку просто. Без канцелярита. Без «снова привет».

---

## Одной фразой

ZeusCode — платформа для кодинга в связке топовых нейросетей.
Один ключ. Один адрес. Ты пишешь задачу — сильные модели делают работу.

---

## Для кого

Для разработчика, вайб-кодера, основателя, который хочет писать продукт быстрее —
и не хочет каждый раз вручную выбирать, какая нейронка сегодня «правильная».

---

## Зачем нужен

1. **Один вход вместо зоопарка.**  
   Не десять кабинетов и десять ключей. Один ключ ZeusCode — и ты в своём окне: Continue, Cline, Roo, Cursor или терминал.

2. **Связка нейросетей, а не одна модель.**  
   Короткая задача идёт быстро и дёшево. Сложная — поднимает сильный стек. Можно собрать свой набор из топовых моделей.

3. **Режимы под задачу, а не под настроение маркетинга.**  
   - Пользовательский — обычные дела, лендинги, мелкие правки.  
   - Продвинутый — серьёзный код и архитектура.  
   - Набор — сам отметь до трёх сильных нейронок, когда нужен максимум без компромиссов.

4. **Обучение без боли.**  
   В приложении бота показывают куда ткнуть и куда вставить — картинками и простым планом. Ключ и модели тоже там.

5. **Советник рядом.**  
   Написал в чат «что взять под оцифровку завода» — получил понятный совет: режим, модели, следующий шаг. Без лекций.

6. **Прозрачный баланс в рублях.**  
   Видишь остаток. Платишь за работу, а не за туманные «кредиты неизвестно чего».

## Чем отличается

| Обычно | В ZeusCode |
|--------|------------|
| Один провайдер, один стиль ответа | Несколько сильных моделей в связке |
| Сам гадаешь, какую модель включить | Режим или советник подсказывают |
| Ключ размазан по гайдам | Ключ и обучение в одном приложении |
| Холодно и «технично» | По-человечески: коротко, по делу, с уважением |

1. Открыл бота.  
2. Увидел баланс и смысл платформы.

4. Вставил ключ в своё окно один раз.  
5. Пишет задачи. Сложное — на сильных. Простое — на быстрых.

## Тон общения (как писать)

Как в хорошем человеческом тексте:

- Говори «ты», спокойно и уважительно.  
- Короткие абзацы. Одна мысль — один кусок.  
- Можно чуть характера, но без крика и без сленга ради сленга.  
- Не «снова привет». Лучше: «Приветствую тебя…».  
- Не сыпь жаргоном (Fusion, OpenAI Compatible, Kie).  
- Ключ в чат не светить — он в приложении.  
- В ответах советника выделяй **жирным** только важное: режим, действие, название.  
- В конце — один следующий шаг. Не десять.

Пример духа (не копируй дословно):

> Послушай. Тебе не нужна лекция про модели.  
> Тебе нужно понять: что включить под твою задачу.  
> Для обычного лендинга хватит пользовательского режима.  
> Если копаешь глубоко и нельзя ошибиться — бери набор из топовых.

## Запрещено в текстах бота

- «Снова привет»  
- Показывать полный или обрезанный ключ в приветствии  
- Длинные стены про Base URL в первом сообщении  
- Кнопки «fallback», шестерёнки «для своих»  
- Упоминания сторонних биллинг-брендов
